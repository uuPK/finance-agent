# Demo Script

## 演示目标

展示系统如何基于赛事官方脱敏数据，从自然语言问题出发，经过 QueryPlan、Guardrail 和 Actor-Critic 修复闭环，最终得到可信查询结果。

## 推荐场景

1. 简单查询

   2026年第一季度，客户交易金额合计是多少？

2. 中等查询

   截至2026年3月31日，持仓市值不少于10万元的客户有多少位？

3. 复杂查询

   截至3月31日总资产不少于30万元且2026年第一季度股票类产品交易金额不少于10万元的客户有多少位？

## 展示顺序

1. 输入自然语言问题。
2. 展示识别出的业务意图和官方元数据召回结果。
3. 展示 QueryPlan。
4. 展示 Critic 检查与修复建议。
5. 展示最终 SQL 和 Guardrail 检查结果。
6. 展示查询结果和自然语言解释。
7. 展示评测中心中的 7 条官方题、60 条官方基础回归题、30 条独立扩展题、真实准确率和失败原因分布；说明扩展题不作为检索样例。

Finance Agent 项目简介
=====================

项目概述
--------

Finance Agent 是一个面向证券客户营销场景的可信智能问数系统。

业务人员可以使用自然语言查询客户画像、资产、资金流、交易、持仓、产品和营业部等
数据。系统会先理解问题并生成结构化查询计划，再生成只读 SQL，经过安全审核和结果
校验后返回查询结果，同时保存完整的执行过程，便于追踪、复核和评测。

本项目对应华泰证券赛题“Agentic 智能问数在客户营销场景的应用”，使用赛事官方脱敏
数据构建，主要用于赛事交付、本地演示、功能验证和智能问数方案研究。


主要功能
--------

1. 智能问数

   用户输入自然语言问题后，系统自动完成元数据检索、问题理解、查询计划生成、SQL
   生成、安全审核、数据库执行和结果解释。

2. SQL 安全控制

   系统只允许执行受限制的只读查询，并对访问表、字段、函数、返回行数和敏感字段进行
   校验，降低错误 SQL、越权访问和提示词注入带来的风险。

3. 查询过程追踪

   系统保存查询运行记录、各阶段事件、查询计划、生成 SQL、审核结果、执行结果和失败
   原因，支持查询历史查看与全过程回放。

4. 元数据管理

   支持管理指标口径、业务术语、表关联、示例问题和规则约束。官方业务表结构保持只读，
   可运营内容集中在语义元数据层。

5. 结果导出

   查询结果可导出为 Excel、CSV 或 JSON，并记录导出行为。

6. 评测与人工复核

   项目提供官方问答、基础回归集、扩展集和多轮独立挑战集，可统计可执行率、结果
   准确率、一次通过率、修复后通过率、耗时和失败原因。评测失败或业务异议可进入人工
   复核流程，并将有效结论回流到元数据和回归案例中。


系统工作流程
------------

    用户自然语言问题
        ↓
    官方元数据检索
        ↓
    结构化查询计划生成与审核
        ↓
    SQL 生成与安全校验
        ↓
    PostgreSQL 只读执行
        ↓
    结果合理性校验
        ↓
    结果展示、导出、审计和人工复核


技术组成
--------

    前端：React、TypeScript、Vite、Tailwind CSS
    后端：Python、FastAPI、SQLAlchemy、Pydantic
    数据库：PostgreSQL 16
    SQL 校验：sqlglot
    模型接口：DeepSeek 或 OpenAI 兼容接口
    依赖管理：uv、npm
    数据库运行环境：Docker Compose


项目数据
--------

项目使用已获授权公开的赛事官方脱敏数据，包含客户画像、客户资产、资金流、客户持仓、
客户交易、产品、机构和公共码表等业务数据。

官方数据保存在：

    data\official\htsc

本项目不应提交真实客户数据、未授权数据、模型密钥、本地数据库卷、审计日志或运行记录。


目录说明
--------

    backend\        后端接口、Agent、SQL 安全控制、评测服务和数据库脚本
    frontend\       智能问数、查询历史、元数据中心和评测中心页面
    data\           官方脱敏数据及数据说明
    docs\           架构、评测、数据集和演示资料
    scripts\        数据初始化及辅助脚本
    docker-compose.yml
                    PostgreSQL 容器配置
    .env.example    环境变量示例
    部署文档.txt   新电脑安装、初始化、启动、验收和故障排查说明


运行地址
--------

系统正常启动后，默认地址为：

    前端页面        http://127.0.0.1:5173
    后端接口        http://127.0.0.1:8000
    后端接口文档    http://127.0.0.1:8000/docs

首次安装或更换电脑部署时，请按照项目一级目录中的“部署文档.txt”操作。


使用边界
--------

当前版本主要面向本地演示和赛事交付。若用于多人协作或生产环境，还需要补充统一身份
认证、角色权限、密钥托管、访问限流、数据库备份恢复、日志留存和生产级服务部署方案。
